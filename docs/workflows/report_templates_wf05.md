## Report Generation Quality Gate Checklist

Before delivering any report to client:

### Accuracy Checks
- [ ] Compliance obligations accurately stated (not overstated)
- [ ] EU AI Act high-risk use cases correctly identified
- [ ] Framework applicability correctly determined (in-scope vs out-of-scope)
- [ ] No hallucinated tool assessments or compliance obligations

### Consistency Checks
- [ ] Dimension scores sum to total score correctly
- [ ] Recommendations align with identified gaps
- [ ] Compliance flags match framework assessments
- [ ] Benchmark comparison uses correct industry sector

### Caveat Checks
- [ ] Data gaps explicitly noted in methodology section
- [ ] Confidence level appropriately assigned
- [ ] "Data not provided" warnings included where applicable
- [ ] Contradictions surfaced if detected

### Formatting Checks
- [ ] All page numbers in TOC are correct
- [ ] Company name consistent throughout
- [ ] All charts/visuals render correctly
- [ ] Booking link functional in Executive Summary

## PDF Generation Implementation Notes

```python
# ReportLab implementation structure
from reportlab.lib import colors
from reportlab.lib.pagesizes import A4
from reportlab.platypus import SimpleDocTemplate, Table, Paragraph, Spacer, Image
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.lib.units import inch

def generate_executive_summary(analysis_output, output_path):
    """Generate 2-page executive summary PDF."""
    doc = SimpleDocTemplate(output_path, pagesize=A4)
    styles = getSampleStyleSheet()
    
    # Custom styles
    title_style = ParagraphStyle(
        'CustomTitle',
        parent=styles['Heading1'],
        fontSize=24,
        spaceAfter=30,
        alignment=1  # Center
    )
    
    # Build story
    story = []
    story.append(Paragraph("AI MATURITY AUDIT REPORT", title_style))
    story.append(Paragraph("EXECUTIVE SUMMARY", styles['Heading2']))
    story.append(Spacer(1, 0.5*inch))
    
    # Score visualization
    score = analysis_output['module_1_maturity']['total_score']
    story.append(Paragraph(f"OVERALL SCORE: {score}/100", styles['Heading1']))
    
    # ... continue building report
    
    doc.build(story)
    return output_path
```
