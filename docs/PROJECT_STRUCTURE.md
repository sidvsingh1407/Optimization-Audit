# Project Structure

- `backend/api`: (Reserved for future API)
- `backend/compliance`: Compliance rules (e.g. EU AI Act, GDPR).
- `backend/config`: Centralized config constants and settings.
- `backend/core`: Core abstractions.
- `backend/models`: Data models.
- `backend/reports`: PDF and report generation.
- `backend/scoring`: Scoring logic and calculations.
- `backend/services`: High level services orchestration.
- `backend/utils`: Shared helpers.
- `frontend`: Streamlit interface.
- `docs`: Documentation and specification files.
- `tests`: Pytest test suite.
- `scripts`: Utility scripts.
- `generated_reports`: Output PDFs.
- `generated_outputs`: Output JSON audit/score files.
